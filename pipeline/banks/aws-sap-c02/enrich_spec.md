# SAP-C02 富化任务规格

> 给解答会话读的任务说明。另开一个 Claude Code 会话，让它读本文件即可接手。
>
> **与 SAA-C03 的最大不同：本题库是英文原版**，因此
> ① 没有译文缺陷（SAA 有四类系统性撞词）
> ② 每题带完整社区讨论（SAA 只有投票百分比）—— 裁决时可读到两派的论证
> ③ 需要产出中文翻译（见「翻译」一节）

## 你的任务

给 `data/aws-sap-c02/questions.json` 的 529 道题补上：

1. **裁决（verdict）** —— 到底选什么
2. **推理（reasoning）** —— 为什么，以及**对立方错在哪**
3. **解析（explanation）** —— 面向学习者的完整讲解
4. **三维标签** —— `domain` / `services` / `concepts`
5. **翻译** —— 题干与选项的中文（见下）

### 为什么裁决是核心

**524 道有对照数据的题里，286 道（54.6%）题库标注与社区投票不一致** ——
比 SAA-C03 的 38% 还高得多。Professional 级题目的标注答案更不可靠，
照搬会背错一半以上。

## 工作循环

```bash
python3 pipeline/core/enrich.py status aws-sap-c02   # 进度（22 片）
python3 pipeline/core/enrich.py next   aws-sap-c02   # 取下一片，输出含 fp
# 写入用 write（不要手写 JSON）：
python3 pipeline/core/enrich.py write  aws-sap-c02 /tmp/shard.py
python3 pipeline/core/enrich.py check  aws-sap-c02   # 必须全绿
```

⛔ **每片开工前必须 `next` 一次**，不能凭上下文里的题面 ——
SAA 那边发生过：上下文压缩后凭记忆写了 11 道题，选项描述全是脑补的。
工具已加强制门禁：每个 item 必须带 `fp`（题面指纹，`next` 输出里给出），
对不上整批拒写。

## SAP 特有的裁决要点

### 「时效性漂移」在 Professional 级更严重

SAA 那边已确认多道题的正确答案随 AWS 特性迭代而变。SAP 题目更老、
涉及的服务更多，这个问题会更频繁。**已知的 AWS 默认行为变更清单**
（SAA 富化侧整理，逐题遇到时对照）：

- **DMS Serverless** 2023 年 GA —— 之前只有「预置复制实例」一种形态
- **AWS 托管 KMS 密钥的轮换周期** 2022-05 前是 3 年，之后改为每年
- **S3 默认加密** 2023-01 起所有新对象默认 SSE-S3
- **S3 桶 ACL** 2023-04 起新桶默认禁用
- **NLB 安全组** 2023-08 起支持（此前不支持）
- **Organizations 声明式策略** 2024-12 起支持下发 EBS 默认加密

遇到时：**按题目成文年代的事实判**，但在 notes 里写明「若按现行 AWS 行为，
答案应为 X」。两种口径都写，学习者才知道这题为什么有争议。

### 反对「题库 + 社区一致意见」的取舍标准

极少数情况下两个来源都错。判断标准（SAA 富化侧确立，沿用）：

> 判错一道题，学习者只是丢一分；
> 跟着错答案走，学习者会把错误的 AWS 事实带进真实架构工作。
> **后者代价大得多** —— 所以按技术事实判，confidence 给 medium，
> 并在 notes 里明确标注「建议人工复核」。

## 翻译

题库是英文，需产出中文以便阅读。约定：

- **AWS 服务名、产品名、专有名词保留英文原文**（`Amazon S3` 不译作「亚马逊简单存储服务」）
- 术语按标准译法，**绝不用会撞词的译名**：
  `Spot` → 竞价（**不能**用「按需」，那是 On-Demand）
  `Serverless` → 无服务器（**不能**用「按需」）
  `provisioned concurrency` → 预置并发 / `reserved concurrency` → 预留并发（两者必须分明）
- 保留原文的强调与并列结构，不做意译润色

> 这三条约定直接来自 SAA 中文版的四类译文缺陷 —— 那些坑不该重踩。

## 质量基准

动笔前读 `data/aws-saa-c03/enriched/0001-0025.json`（SAA 的样板片）。
要点：reasoning 直接对线并说清错的一方错在哪；explanation 给**可迁移的判据**
而非复述答案；服务边界辨析用对照表。
